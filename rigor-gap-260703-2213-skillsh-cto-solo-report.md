## Góc nhìn lãnh đạo (đọc 60s)

**skillsh lỏng nhất ở 4 điểm, 3 trong số đó ĐÃ thủng thật trong run đầu tiên (rebuild-hex-agent):**

Không một verdict nào kèm bằng chứng lệnh-chạy-thật hay file ký.
2. **Biên không-đảo-ngược không có sàn** — toàn bộ skillsh + state 3 project sống NGOÀI git (ghi đè là mất vĩnh viễn); không gì gác secret trong diff hay `git push --force origin main` lên repo khách.

**Tổng: 18 gap giữ lại** (2 keep nguyên, 16 downscope sau red-team, 0 drop hẳn; 19 mục gộp/loại ở vòng consolidation). Sau downscope: 17 gap hạng S (nửa buổi–1 buổi/gap) + 1 hạng M (fresh-run-evidence). **Tổng công ước tính ~8–10 ngày, chia 3 đợt.** Phần lớn là sửa SKILL.md + vài script stdlib chạy tay; chỉ 4 hook mới (push-boundary, write-guard mini, gate_ship, bash-safety) — tất cả đều 1 file tự chứa.

- **Đợt 1 — sàn (1 ngày):** git-floor (git init + CLAUDE.md nhịp commit) → mọi thứ sau đó mới tamper-evident. Kèm push-boundary-hook.
